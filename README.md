# Telegram → Yandex IoT Scenario Trigger

Go-скрипт для **мониторинга публичных Telegram-каналов** и **автоматического запуска сценариев Yandex Smart Home (IoT)**
при появлении заданных ключевых слов.

Основной практический кейс — **получение информации о ракетной опасности и других экстренных оповещениях** из публичных
Telegram-каналов с последующим запуском сценария умного дома.

---

## Особенности

*  **Не использует MTProto API**

    * не нужен `api_id` и `api_hash`
    * не требуется Telegram-аккаунт
    * нет риска блокировки аккаунта
*  Работает через **публичный HTTP-доступ** к Telegram-каналу

---

##  Логика работы

1. Скрипт периодически загружает HTML-версию публичного Telegram-канала
2. Извлекает **последнее сообщение**
3. Проверяет наличие триггерных слов
4. При совпадении:

    * получает ID сценария Yandex Smart Home по имени
    * отправляет запрос на запуск сценария
    * повторно запускает сценарий через 5 секунд (для надёжности)

---

## Зависимости

* Go **1.21+**
* Используемые библиотеки:

    * [`goquery`](https://github.com/PuerkitoBio/goquery) — HTML-парсинг
    * [`godotenv`](https://github.com/joho/godotenv) — загрузка переменных окружения

### Пример `.env`

```env
# URL публичного Telegram-канала
CHANNEL_URL=https://t.me/s/your_channel_name

# Триггерные слова (через запятую, в нижнем регистре)
TRIGGER_WORDS=ракетная опасность,воздушная тревога,тревога

# Имя сценария в Yandex Smart Home
SCENARIO_NAME=Опасность

# OAuth-токен Yandex Smart Home
YANDEX_TOKEN=your_yandex_token_here

# Интервал проверки канала (в секундах)
PARSING_SLEEP_TIME=30
```
